# 术语表

本表定义 [SKILL.md](../SKILL.md)、`references/` 与维护文档共用的 20 个术语。定义只描述可判定的状态，不含操作建议。术语列与 [scripts/terms.json](../scripts/terms.json) 的 `terms` 数组逐字一致、顺序一致；「不要写成」列的每一项与 `forbidden` 数组逐字一致。「不要写成」列用顿号分隔，每个顿号之间的一项都是一个禁用替代词。

| 术语 | 定义 | 不要写成 |
|---|---|---|
| 未判 | 入口的默认状态，表示类型尚未由 P0 探针产生；它是合法状态，不是错误。 | 待分类、没头绪 |
| 探针 | 一次有成本上限的动作，用来说明读者是谁、要决定什么；结果决定文档类型。 | 摸底、先看看 |
| 门禁 | 一份文档被标为完成前必须满足的断言；不满足就不能交付。 | 核对点、注意事项、视情况、酌情 |
| 目的闸 | §1 的入口检查：确认读者与决定，答不上来不写第一句正文。 | 需求确认、对齐目标 |
| 结构闸 | §3 的骨架检查：先定一句话结论与节级断言，骨架不过不展开正文。 | 列大纲、搭框架 |
| 删减闸 | §4 的写完检查：按删节测试、重复、密度、长度预算、混装五项逐项删。 | 修修补补、精修、尽量、根据需要 |
| 决策文档 | 读者要在多个方案间选一个的文档；必须含被否决方案与否决理由。 | 方案说明、设计稿 |
| 证据文档 | 读者要基于事实判断形势的文档；每条结论挂证据强度，且至少一条反证。 | 资料汇编、背景材料 |
| 操作文档 | 读者要照着做成一件事的文档；每步可执行且可验证，含失败处理。 | 入门指南、说明手册 |
| 参考文档 | 读者要查一个确定条目或参数的文档；条目化，无叙事。 | 速查表、百科 |
| 解释文档 | 读者要理解为什么会这样的文档；写机制与边界，不用比喻代替机制。 | 通俗读物、原理介绍 |
| 结构物 | 第 2 段给读者定位用的组件图、分层表或主路径链，必须写出部件与连接；不是概述。 | 概述、目录、摘要 |
| 理解门 | 写完自检的三条判据：能复述整体结构、能定位任一细节节、能回答一个未写出的场景。 | 读后感 |
| 改写模式 | 输入是已有文档时的流程：诊断卡点、重判类型、抽取承重信息、重排。 | 润色 |
| 一句话结论 | 首段那句可被反驳的判断，含对象、判断、条件。 | 中心思想、全文概述 |
| 删节测试 | 逐节自问"删了它，读者的决定会变错吗"，答不出即删。 | 瘦身、压字数 |
| 混装 | 一个文件同时承载两种以上文档类型。 | 综合文档、大杂烩 |
| 体检表 | 报告层的别称，指交付对话里的 7 行检查记录，含类型、结论、读者、删减、证据强度、未验证、私有条件缺口；不写入文档正文。 | 读后感、使用说明 |
| 私有条件 | 会翻转文档结构或结论的读者、组织、合规条件，最多 5 条。 | 背景信息、补充说明 |
| 观测级 | 断言由可直接观测的数据支撑，可写进结论句。 | 板上钉钉、确凿 |
| 推断级 | 断言由观测数据经关系式推出，可写进结论句并标出推导。 | 大概、推测 |
| 叙事级 | 由故事、类比或常识推出、没有数据与关系式的断言，不得写进结论句。 | 直觉、经验之谈 |
| 承重件 | 文档中删掉会让读者决定变错、或改动会改变门禁与输出契约的部分。 | 精髓、干货 |
