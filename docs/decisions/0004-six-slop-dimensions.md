# 0004 AI 味六项

- 状态：已接受
- 日期：2026-11-01

## 背景

"AI 味"是一个模糊指控。作者无法据此修改，评审者也无法据此判定。要把它变成可执行的标准，必须落到可观察的文本特征上。

Shaib et al., 2026, arXiv:2509.19163 把 AI 低质文本的维度分为三类：信息效用（密度、相关性）、信息质量（事实性、主观性）、风格质量（重复、模板化、连贯、冗长、词复杂度、语气）。全量维度里有一部分无法靠阅读一份文档判定，例如事实性需要外部来源核查。

## 决策

只保留能靠阅读直接判定的六项：密度、重复、模板化、冗长、复杂度、语气。每项给失败签名与修法，不给"要自然"这类标准。判据见 [SKILL.md](../../SKILL.md) §5。

信息质量维度不并入这六项，由证据分级单独处理：观测级、推断级可进结论句，叙事级不得进结论句。两份判据各管一件事，不互相替代。

## 后果

评审者可以指着具体句子说"这是模板化句首"或"这句超过 40 字"，作者知道改哪一句。六项覆盖风格与效用，不覆盖事实正确性。

代价是仍有遗漏：连贯性与相关性只被部分覆盖。处理方式是出现新的可阅读判据时，按 minor 版本加入第六项之后的清单，不改三项分类本身。

## 备选方案

- 用"要自然""要有洞察力"作为标准：不可判定，评审者与作者对同一句会给出不同结论。
- 全量引入三类维度：事实性需要外部核查，不是文档写作能判的；把不可判定的项写进清单，会让整张清单失去可执行性。
- 用检测器打分：分数不告诉作者改哪一句，也不解释失败在哪一项。
- 只做密度检测：密度低是结果，重复、模板化、冗长、名词化是成因；只删低密度段落会让剩下的段落依旧模板化。
