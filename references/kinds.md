# 文档类型与结构模板
> 何时读我：P0 跑完仍判不出类型，或写完发现一个文件里同时有两种读者。

类型判据只有一条：读者读完要做什么动作。标题、篇幅、模板都不参与判定。本文件给五类文档的骨架与"不该出现的元素"，以及混装文档的拆分结果。

## 与 Diátaxis 的对应

Diátaxis 按"学习 / 任务 / 查询 / 理解"四象限划分文档（diataxis.fr）。本方法五类里，三类落在四象限内，两类不在。

| 本方法类型 | Diátaxis 象限 | 读者动作 | 说明 |
|---|---|---|---|
| 操作文档 | tutorial | 跟着做，第一次学会 | 教程是本类型的入门档，骨架相同 |
| 操作文档 | how-to | 已会，要解决一个具体任务 | 与 tutorial 共用骨架，前置条件写得更硬 |
| 参考文档 | reference | 查一个确定条目 | 只查不读，无叙事 |
| 解释文档 | explanation | 理解机制与边界 | 讲为什么，不讲怎么做 |
| 决策文档 | 无 | 在多个方案间选一个 | 四象限不覆盖组织内决策，按 Malte Ubl《Design Docs at Google》(2020) 的结构 |
| 证据文档 | 无 | 基于事实判断形势 | 按结论与证据强度组织 |

四象限不替你判类型，它只解释为什么"教学 + 查询"混在一起会互相拖垮。

## 骨架与禁区

### 决策文档
二级标题清单：问题与约束 / 目标 / 非目标 / 方案 / 取舍 / 已否决方案 / 跨切面。

| 不该出现的元素 | 原因 |
|---|---|
| 完整实现步骤 | 那是操作文档，读者会照着做而不是做决定 |
| 逐参数 API 表 | 那是参考文档，会挤掉取舍 |
| 收益的形容词描述 | 不可反驳，进不了结论 |
| 无否决理由的候选清单 | 读者无法判断你比过什么 |

### 证据文档
二级标题清单：结论 / 证据 / 反证 / 不确定性 / 建议。

| 不该出现的元素 | 原因 |
|---|---|
| 检索日志、抓取记录 | 过程不是证据 |
| 未消化的引文堆 | 每条证据要挂到一条结论 |
| 结论段里的叙事级判断 | 叙事级不得进结论句 |
| 与结论无关的背景章节 | 删了不改变判断 |

### 操作文档
二级标题清单：前置条件 / 步骤 / 每步验证 / 失败处理。

| 不该出现的元素 | 原因 |
|---|---|
| 机制长段解释 | 读者卡在第一步 |
| 多方案对比 | 要选方案的是决策文档 |
| 历史沿革 | 与执行无关 |
| 无验证动作的步骤 | 无法判断是否成功 |

### 参考文档
二级标题清单：按对象分节，每节内部为 定义 / 参数 / 版本 / 示例。

| 不该出现的元素 | 原因 |
|---|---|
| 叙事过渡句 | 破坏条目独立性 |
| 首先、其次 | 条目之间没有顺序 |
| 教学式铺垫 | 查的人不需要入门 |
| 跨条目重复定义 | 改一处会漏一处 |

### 解释文档
二级标题清单：现象 / 机制 / 边界。

| 不该出现的元素 | 原因 |
|---|---|
| 操作步骤 | 要动手的人去读操作文档 |
| 参数表 | 要查数值的人去读参考文档 |
| 比喻替代机制 | 比喻不能预测边界行为 |
| 只有现象没有机制 | 那是证据文档的观测段 |

## 判定细则

判不出类型时，按顺序问下列问题，第一个答"是"的就是类型。

| 顺序 | 问句 | 是 → 类型 |
|---|---|---|
| 1 | 读者要照着做成一件事？ | 操作文档 |
| 2 | 读者要在多个方案间选一个？ | 决策文档 |
| 3 | 读者要基于事实判断形势？ | 证据文档 |
| 4 | 读者要查一个确定条目？ | 参考文档 |
| 5 | 读者要理解为什么会这样？ | 解释文档 |

五问全否，状态是「未判」，回到 P0，不要先选模板。

## 三个混装实例

### 实例 1：选型文档里塞了迁移手册
原文结构：候选对比 / 压测数据 / 迁移步骤 / 回滚脚本 / 参数表。
拆分：决策文档留住候选对比、压测数据、已否决方案；迁移步骤与回滚脚本另存为操作文档；参数表另存为参考文档。决策文档里只留一行链接。

### 实例 2：调研报告前半讲原理
原文结构：原理科普 / 市场数据 / 厂商评估 / 结论。
拆分：原理科普抽成解释文档，结论段只留一句"机制见附件"；主体改成证据文档：结论 / 证据 / 反证 / 不确定性 / 建议。原理不再占正文页数。

### 实例 3：接入指南混了教程与参数
原文结构：概念介绍 / 三步接入 / 完整参数表 / 常见问题。
拆分：三步接入写成操作文档，每步加验证；参数表进参考文档；概念介绍压成一段前置说明或外链解释文档；常见问题按性质归入失败处理或参考文档。

三个实例的共同点：混装不是排版问题，是同一段文字在服务两种读者动作。拆分判据是读者动作，不是章节名字。
