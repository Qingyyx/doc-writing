# 改写模式：从旧文档到新文档

> 何时读我：手上已有一份文档，要在它基础上重写，而不是从零写。

## 与从零写的差别

从零写先问"读者要做什么"。改写先问"原稿让读者在哪卡住"。原稿的结论可能对但组织不对，也可能结论本身要重判。两种情况的动作不同：前者重排，后者重写结论。

不要在旧结构里换措辞。换措辞不改阅读体验，等于没改。

## 第一步：诊断原稿的六个卡点

逐条勾，命中的就是重写时要修的位置。

| 信号 | 判据 | 处理 |
|---|---|---|
| 结构缺席 | 读完前三分之一，说不出由哪几部分组成 | 补结构物 |
| 细节先于结构 | 第 2 段就开始讲某个参数、步骤或实现 | 把细节挂回结构物，前面补结构 |
| 过程当结论 | 大段写"我们调研了…""经历了三轮讨论" | 删过程，只留结论与证据 |
| 术语未定义 | 关键名词首次出现即使用，全文没有一句定义 | 首次出现处补一句，或进术语表 |
| 类型混装 | 同一文件里既有选型论证，又有操作步骤 | 拆成两份，主文件只留一种 |
| 证据缺失 | 结论句里没有数值、来源或推导 | 补来源，补不上就降级为"未验证" |

六个信号里命中三个以上，不要修补，直接按新骨架重写。

## 第二步：重判类型

原稿标题写的类型，不等于读者动作的类型。按五类重判：读者读完是要做决定、判断形势、照着做、查条目，还是理解机制。重判后结构可能整体换掉，这是正常的。

## 第三步：抽取承重信息

只抽五类，其余一律视为过程性内容：

| 类别 | 问句 |
|---|---|
| 结论 | 原稿主张什么，在什么条件下成立 |
| 结构 | 有哪些部件，部件之间怎么连接 |
| 证据 | 哪些数字、观测、外部资料有出处 |
| 边界 | 什么情况下不成立、不适用 |
| 取舍 | 放弃了哪些方案或范围，为什么 |

抽不出来的项，说明原稿没有。需要新写，不能用原文的形容词顶替。

## 第四步：重排

1. 先写一句话结论。可以改原稿的结论，不必保留原句。
2. 选结构物：分层关系用表，流程用链，依赖关系用图。结构物必须能让读者定位后续每一节。
3. 每个细节节挂到一个节点。挂不上的节，删掉或并入相邻节。

## 第五步：报告层加两行

改写模式在 7 行之外再加两行：

- 原稿主要问题：<第一、二步命中的信号>
- 删掉的内容类别：<过程 / 重复 / 混装 / 无来源断言>

## 三个陷阱

- **只换措辞不换结构**：读者体验不变。判断标准是结构物是否新增或重画。
- **保留原稿目录**：目录是旧结构的化石。重排后必须重写目录，不能沿用。
- **把"原文没写"当成"不需要"**：原稿缺结构物时，要新写结构，不能因为原文没有就删掉这一层。
